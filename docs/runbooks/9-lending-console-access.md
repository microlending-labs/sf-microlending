# Lending Console: granting access (#9)

Run after the deployment of the `Lending_Console` app and `Lending_Console_User` permission set.

1. Setup > Permission Sets > `Lending_Console_User` > Manage Assignments > Add Assignments.
2. Select the users who should work in Lending Console and save.
3. Verify: a user with the permission set sees `Lending Console` in the App Launcher; a user without it does not.

Assignments are not metadata and are not deployed, so this step is repeated in every org.
