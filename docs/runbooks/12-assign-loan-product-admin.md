# Assign Loan_Product_Admin (ticket #12)

Applies to: UAT, production and any new DEV org.

## Steps
1. Setup -> Users -> Permission Sets -> Loan Product Admin -> Manage Assignments -> Add Assignments.
2. Select the System Administrator user(s) who maintain the loan catalogue -> Assign -> Done.

## Check
1. Log in as that user, App Launcher -> Loan Products.
2. New: all 11 fields are shown and editable.
